# Hitha G Gowda — Portfolio

A responsive single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy free
- **Vercel:** Import the folder/repository as a project. No build command is required; set the output directory to `.`.
- **GitHub Pages:** Push the files to a repository, then enable Pages from the repository's Settings.

## Before publishing
- Add a PDF resume file and link a "Download Resume" button if you want one.
