// OPEN MARINE API

Public REST API for Researchers

Free-tier access for NGOs and academic institutions. Query real-time marine health data, hotspot locations, and biodiversity indices.

GET
/v1/hotspots?zone=gulf_of_mannar
Returns all active pollution hotspots within a named marine zone, including severity, type, and PostGIS coordinates.
{
  "type": "FeatureCollection",
  "features": [{
    "geometry": {"type":"Point","coordinates":[79.14,9.21]},
    "properties": {"severity":0.87,"type":"plastic"}
  }]
}
GET
/v1/zones/:id/health
Returns the Marine Health Index score (0–100) for a specific zone, with sub-scores for plastic density, biodiversity, and chemical levels.
{
  "zone_id": "gulf_of_mannar",
  "health_index": 68,
  "plastic_density": 0.42,
  "biodiversity_score": 0.74,
  "updated_at": "2026-04-01T09:12:00Z"
}
POST
/v1/reports/sighting
Submit a citizen sighting — plastic debris, stranded marine animals, or illegal fishing activity. Coordinates auto-geocoded.
{
  "lat": 9.21, "lon": 79.14,
  "sighting_type": "plastic_debris",
  "image_url": "https://...",
  "severity": "high"
}
GET
/v1/buoys/:id/stream
WebSocket stream of live sensor readings from a specific buoy — pH, temperature, turbidity, and microplastic count per litre.
// WebSocket event payload
{
  "buoy_id": "MN-047",
  "ph": 8.12, "temp_c": 28.4,
  "turbidity_ntu": 4.7,
  "microplastic_m3": 2340
}
